# GitHub Desktop 3.1.6 简体中文汉化包

此分支保存适用于 **GitHub Desktop 3.1.6（Windows）** 的历史汉化包。请在「帮助 → 关于」确认完整版本号。

[下载 3.1.6 分支 ZIP](https://github.com/Johnserf-Seed/GitHub-Desktop-Chinese-Language-Pack/archive/refs/heads/version/3.1.6.zip) · [查看汉化文件](app-3.1.6/) · [返回主分支查看最新版和其他版本](https://github.com/Johnserf-Seed/GitHub-Desktop-Chinese-Language-Pack#历史版本)

## 安装与恢复

1. 下载并解压上面的 ZIP，正常退出 GitHub Desktop。
2. 打开 `%LOCALAPPDATA%\GitHubDesktop\app-3.1.6\resources\app`，把原有的 `main.js` 和 `renderer.js` 复制到单独的备份目录。
3. 从压缩包的 `app-3.1.6/resources/app/` 复制同名文件到安装目录，重新启动 GitHub Desktop。

恢复英文界面时，退出程序，再将备份的两个原文件复制回去。
