# GitHub Desktop 3.6.6 简体中文汉化包

此分支保存适用于 **GitHub Desktop 3.6.6（Windows）** 的历史汉化包。请在「帮助 → 关于」确认完整版本号。

[下载 3.6.6 分支 ZIP](https://github.com/Johnserf-Seed/GitHub-Desktop-Chinese-Language-Pack/archive/refs/heads/version/3.6.6.zip) · [查看汉化文件](app-3.6.6/) · [返回主分支查看最新版和其他版本](https://github.com/Johnserf-Seed/GitHub-Desktop-Chinese-Language-Pack#历史版本)

## 安装与恢复

1. 下载并解压上面的 ZIP，打开 `app-3.6.6/` 文件夹。
2. 正常退出 GitHub Desktop，双击 `install.cmd`。安装完成后重新启动程序。

需要恢复英文界面时，退出程序并运行同一文件夹中的 `restore.cmd`。若已安装过同版本的另一份汉化，请先恢复，再安装此包。
